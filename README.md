## Практическая работа №5

1. **Кто проверяет повтор?** Сама гильдия (класс `Guild`), потому что правило «двух одинаковых нет» принадлежит ей. `Program` только просит добавить.
2. **Когда `FindHeroByName` возвращает `null`?** Если имя пустое или в списке нет героя с таким именем.
3. **Зачем очищать запрос?** Пользователь может ввести « аРтЁм » с пробелами. Метод делает `Trim()`, чтобы найти Артёма.
4. **Почему `MemberCount` вычисляется?** Внутри хранится `_heroes.Count`. Если хранить число отдельно, можно забыть обновить его после добавления/удаления.
5. **Удаление уничтожает героя?** Нет, объект остаётся в памяти (если на него есть другая ссылка), просто убирается из внутреннего списка.
6. **Почему `private`-поле не защищено, если вернуть его из метода?** Внешний код получает ссылку на тот же список и может вызвать `.Clear()`. Нужно возвращать **новый** список с копиями ссылок.

**Трассировка:** прогноз — `True, False, True, True, 1, 2, True` (совпало).
**Ошибка 1:** `return null` внутри цикла завершает метод после первого несовпадения.
**Ошибка 2:** `return _heroes;` возвращает оригинал, `private` закрывает только имя.

### Личный проект
Ключ — название товара. Подведёт, если два разных товара называются одинаково (например, два вида «Чебурек»). Поиск возвращает `null`, если товара нет — `Program` проверяет через `if (found != null)`.
