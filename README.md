## Практическая работа №4

1. **Что хранит элемент List<Hero>?** Ссылку на объект Hero, а не его копию.
2. **Почему созданный через new Hero(...) объект ещё не в списке?** Потому что его туда не добавили через Add.
3. **Чем Count отличается от последнего индекса?** Count — количество (5), последний индекс — Count - 1 (4).
4. **Что обозначает hero в foreach?** Текущий элемент списка на каждом проходе.
5. **Почему урон через переменную виден и через список?** Список хранит ссылку на тот же объект, а не копию.
6. **Что private set у Heroes запрещает, а что пока разрешает?** Запрещает заменить весь список, но разрешает добавлять элементы через Add.

**Трассировка:** мой прогноз — 3 записи, 2 объекта; фактический — совпало.
**Ошибка 1:** использован индекс Count вместо Count - 1 → ArgumentOutOfRangeException.
**Ошибка 2:** создан новый объект вместо ссылки → здоровье не менялось в списке.
**Самостоятельный шаг:** подсчёт >= 120 дал 2; самый здоровый — Александр (150).
